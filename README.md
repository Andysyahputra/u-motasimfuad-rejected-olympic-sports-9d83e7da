An entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) "Rejected Olympic Sports" bounty. `main.ts` (Node 22, standard library only) writes one funny single-line sport the Olympics rejected to `/output/entry.txt`:

> Freestyle 200m Walking Into A Room And Forgetting Why

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
